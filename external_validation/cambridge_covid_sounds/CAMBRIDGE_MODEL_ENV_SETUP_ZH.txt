三、下载模型（只在集群尚无模型时）
--------------------------------

模型可以放在不受 Git 管理的共享模型目录，例如：

mkdir -p /home/yl809/models
python -m pip install "huggingface_hub[cli]"

下载 AST：

hf download MIT/ast-finetuned-audioset-10-10-0.4593 \
  --local-dir /home/yl809/models/ast-finetuned-audioset-10-10-0.4593

下载固定 revision 的 Phi-2：

hf download microsoft/phi-2 \
  --revision 810d367871c1d460086d9f82db8696f2e0a0fcd0 \
  --local-dir /home/yl809/models/phi-2

准备 OPERA 源码和权重：

git clone https://github.com/evelyn0414/OPERA.git /home/yl809/models/OPERA
mkdir -p /home/yl809/models/OPERA/cks/model
curl -L --fail --retry 5 \
  https://huggingface.co/evelyn0414/OPERA/resolve/main/encoder-operaCT.ckpt \
  -o /home/yl809/models/OPERA/cks/model/encoder-operaCT.ckpt

冻结代码会核对 OPERA-CT checkpoint；预期 SHA-256 为：

83c35b435518ad5f395bf4d34e552caa088faf9e63f6b8058d5288e9abb350ae

手工核对：

sha256sum /home/yl809/models/OPERA/cks/model/encoder-operaCT.ckpt

作业首先检查：配置版本、GO 解锁、四个模型路径和 GPU CUDA；通过后依次完成 Phi-2 缓存、
AST-6L/OPERA-CT 提取、Correct/Within-label/Global × 5 seeds × 500 epochs、最终评测与
公开聚合结果打包。文本缓存、表示提取和已经完整写出 manifest 的 backbone 可以复用；若在
某个 backbone 的15个alignment runs中途超时，该backbone会从头重跑。因此首次建议申请
4小时；2小时可以尝试但偏紧，1小时不建议。

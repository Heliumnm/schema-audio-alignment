CAMBRIDGE COVID-19 SOUNDS 外部数据门快速指南
=============================================

用途
----

本指南用于运行 Cambridge COVID-19 Sounds COVID 阳性与阴性的冻结、
模型盲态数据可行性检查。

第一阶段不会加载 AST、OPERA、Phi-2，不会生成 embedding、prediction、AUROC
或 NLL。它只检查数据能否支撑事先规定的外部验证。


一、需要准备的 Cambridge 数据
-------------------------------

请在获得授权的 DTA 环境中准备以下两部分数据。

1. 完整 metadata 文件夹

   covid19/metadata/

   其中应包含 android.csv、ios.csv 和 web.csv。程序会自动识别三份文件的
   分号分隔格式及空索引列，根据 uid 与 Task 2 表连接，并解析 Age、Sex、
   Smoking、Symptoms 和 Medhistory，不需要手工转成逗号 CSV。

2. 一份音频目录，下面两种任选一种

   推荐使用体积较小的 Task 2 音频子集：

   task2/0426_EN_used_task2/

   或者使用完整音频母目录：

   covid19/

   完整音频目录可能是以下结构：

   covid19/
     participant_ID/
       collection_time/
         audio_file_breathe.wav
         audio_file_cough.wav
         audio_file_read.wav

   程序用 Uid + Folder Name 把 metadata 和同一次采集的 cough 连接，只使用
   文件名包含“cough”的录音。同一位参与者最终只作为一个患者级分析单位。

本次发布包中没有 data_0426_en_task2.csv，所以不需要也不应虚构该文件。
程序会从 metadata 严格重建 cohort，并明确标记它不是官方 split 复现。

本阶段不需要下载：

- Task 1；
- openSMILE 特征；
- Dataset Document.xlsx；
- breathing 或 read/voice 特征；
- AST、OPERA、Phi-2 模型文件。


二、下载实验代码
----------------

git clone --depth 1 https://github.com/Heliumnm/schema-audio-alignment.git
cd schema-audio-alignment/external_validation/cambridge_covid_sounds


三、创建数据门运行环境
----------------------

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements-gate.txt


四、运行模型盲态 match-first v2 数据门
--------------------------------------

把下面三个示例路径替换为本地绝对路径：

bash run_reconstructed_match_first_v2.sh \
  /DATA/covid19/metadata \
  /DATA/test2 \
  /DATA/cambridge_match_first_v2

如果 Task 2 音频子集实际位于别处，只替换第二个路径。它必须保持：

  Task2根目录/UID/Folder Name/cough WAV

该v2先在全部可用参与者中冻结恰好100对matched target，再把剩余人按
label × platform固定分成70% train、15% validation、15% source-test。
如果Task-1已经下载，可追加其路径作为可选第四参数做跨任务聚合overlap；未下载则明确记为
未测量，不阻塞，因为Task 1不进入拟合。不要改回run_reconstructed_gate.sh；后者是已记录为
NO_GO的历史v1。


五、查看数据门结果
------------------

聚合结果位于：

/DATA/cambridge_match_first_v2/public/DATA_GATE_REPORT.md
/DATA/cambridge_match_first_v2/public/data_gate.json
/DATA/cambridge_match_first_v2/public/PUBLIC_RESULTS.zip

如果结果是 NO_GO：

- 立即停止；
- 不得修改 100 对、0.12 SMD 或 0.08 fine-balance 门槛；
- 不得运行任何模型；
- 只返回 PUBLIC_RESULTS.zip、Git commit SHA 和运行环境说明。

如果结果是 GO：

- 先把 PUBLIC_RESULTS.zip 发给项目负责人独立核对；
- 在项目负责人明确提供正式解锁指令前，不得运行正式模型阶段。


六、隐私边界
------------

不得发送、上传或提交以下目录中的任何内容：

/DATA/cambridge_match_first_v2/private/

该目录包含 participant ID、音频路径、匹配关系和其他逐患者材料，必须留在
获得授权的 DTA 环境中。

默认只返回聚合结果压缩包：

/DATA/cambridge_match_first_v2/public/PUBLIC_RESULTS.zip

如果当地 data steward 或 DTA 有更严格的规定，应以其规定为准。

八、重建规则（不得修改）
------------------------

- 只保留 Language=en；
- 阳性只接受 positiveLast14 / last14；
- 阴性只接受 negativeNever；
- 同一患者若跨时间同时出现正负标签，整人排除；
- 每人固定选择一个有 cough 的采集时点；
- 先对全部符合条件的参与者匹配并冻结100对matched target；
- 只把剩余参与者按label × platform分层、固定哈希切为70%/15%/15%；
- 这是secondary match-first v2，不能声称复现官方Task-2 split或untouched confirmation；
- 任何数据门阈值都不能为了得到 GO 而修改。

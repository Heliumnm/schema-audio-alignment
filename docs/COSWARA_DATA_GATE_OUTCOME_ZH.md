# Coswara 外部数据门结果

日期：2026-08-20  
预注册协议：`docs/COSWARA_EXTERNAL_PREREG.md`  
冻结实现：`6d783a4`  
决定：**NO-GO，不启动 Coswara 模型实验**

> 2026-09-03 补充：原结论对冻结的贪心路径仍成立。一个单独标记、在模型分数盲态下冻结的
> 全局约束敏感性分析后来找到了满足原门槛的 100 对队列（年龄 SMD 0、最大分类 SMD
> 0.1034、最大层级比例差 0.07）。因此现在允许做 post-hoc external stress test，但不把原
> `NO-GO` 改写成预注册外部确认。详见 `docs/COSWARA_GLOBAL_GATE_SENSITIVITY_ZH.md`。

## 一句话结论

Coswara 的音频下载、提取和逐文件质检都成功完成，但在客观音频 QC 后，预注册的
1:1 患者匹配队列无法同时满足“至少 100 对”和协变量平衡门槛。因此外部模型分支
按计划关闭；没有训练 Coswara projector，也没有读取任何 Coswara 模型预测。

## 实际执行结果

- Zenodo v1.0 归档：12,984,309,908 bytes，MD5 与官方值一致；
- 43/43 个日期流全部验证并完成；
- 每名参与者只保留一条 `cough-heavy.wav`；
- 共提取 2,746 人、2,746 条录音，约 1.5 GiB；
- 2,746 条全部可以解码，2,646 条通过客观音频 QC；
- 49 条短于 0.5 秒，97 条为全零波形，两类有重叠；
- 无非有限值、无头信息与解码帧数不一致、无一人多条录音；
- 发现 7 组跨参与者完全重复的原始文件/PCM 波形，冻结分组时禁止跨 split；
- 513 人没有人工质量标注。人工质量从未作为主队列纳入条件；
- 2,159 条归档批次日期与自报录制日期不同，按预注册只作诊断，不作为排除条件。

## 为什么没有进入模型实验

冻结门槛要求：

1. 主分析至少 100 个正负匹配对；
2. 年龄和分类协变量的最大绝对 SMD 不超过 0.12；
3. 每个细平衡层级的最大比例差不超过 0.08；
4. 开发集规模、身份唯一性和 PCM 跨 split 检查全部通过。

客观 QC 与去重后有 1,701 名合格参与者，其中严格疾病确认候选 760 人。精确匹配
最多产生 112 对。冻结的确定性修剪一直执行到最低允许的 100 对，最终：

- 年龄 SMD：-0.0017，通过；
- 最大分类 SMD：**0.1401，超过 0.12，失败**；
- 最大层级比例差：约 0.0800，处在门槛边界；
- 开发集规模门：通过；
- 综合外部数据门：**失败**。

两个敏感性队列也不能承担正式结果：人工质量 1/2 队列只有 57 对；已知检测类型
队列虽有 60 对，但平衡失败。

## 这意味着什么

这是**数据可行性 NO-GO**，不是模型负结果，更不是“Coswara 上方法失败”。模型阶段
根本没有开启。不能改变匹配字段、标签定义、音频模态、QC 阈值或平衡门槛来挽救
样本量，否则会破坏预注册的意义。

对 ICASSP 稿件的准确表述是：我们在读取任何外部模型分数之前执行了预注册的
患者级外部数据门；真实音频 QC 后，候选队列在最低样本量处仍未达到协变量平衡，
因此透明地停止外部实验。论文仍然是 UKCOVID 的 pairing-controlled discovery audit，
不能声称跨数据集确认。

# ICASSP 执行状态（2026-08-19）

## 论文现在讲什么

这不是一篇“提出更强模型”的论文，而是一篇临床音频对齐的受控审计：

> 当训练数据中的疾病标签几乎等于招募来源时，把音频对齐到年龄、症状和病史，究竟
> 学到了能跨人群迁移的疾病证据，还是只学到了患者／队列结构？

关键实验不是只比较“对齐前后”，而是同时训练三组：

- `correct`：每条音频配本人的 metadata；
- `within-label`：只在相同疾病标签内部打乱 metadata，保留标签级共现、破坏逐人对应；
- `global`：全局打乱，破坏全部对应。

因此 `correct - within-label` 回答的是：逐患者的正确配对本身到底买到了什么。

## 已经完成

### UKCOVID 发现性审计

- 招募来源预测 COVID：Standard train AUROC `0.9966`，matched 为 `0.5000`；
- Standard 上 `correct - within-label` 的 AUROC 为
  `+0.0140 [0.0040, 0.0235]`，说明正确配对确实学到了一点个人对应；
- matched 主结果 `Delta(-NLL) = -0.0249 [-0.0443, -0.0069]`，五个 seed
  全为负；AUROC 增量 `+0.0062 [-0.0144, 0.0279]`，区间覆盖 0；
- matched-long 的 NLL 方向一致；
- probe 显示正确配对相对同标签打乱显著保留性别、较弱保留年龄，但没有形成可迁移的
  疾病收益。

准确结论是：**在 UKCOVID 这个高度混淆的场景和当前 Stage-1 对齐实现里，正确
metadata 配对学到了真实的患者对应，却没有改善协变量平衡人群中的校准疾病预测。**
不能写成“metadata alignment 普遍无效”或“AST 没有疾病信息”。

## 下载完成后的唯一顺序

1. 核对精确字节数、官方 MD5、ZIP CRC、43 个日期和 153 个分卷；
2. 先对一个真实日期做流式解包和 QC smoke test；
3. 只提取每位参与者的 `cough-heavy.wav`，全量做解码、时长、全零、PCM hash 和
   跨 ID 重复审计；
4. 用冻结规则生成患者级 train／validation／source-test 和 matched evaluation；
5. 读取数据门：至少 100 对且平衡与开发集样本量全部通过；
6. **若 GO**：再冻结文本模板、模型 hash 和 evaluator，训练三组对齐，最后一次性解锁
   external stress-test；
7. **若 NO-GO**：停止 Coswara 模型实验，不换录音、不放宽标签、不移动匹配阈值；
   稿件如实写成 UKCOVID discovery audit，并决定补第二个 backbone 还是转 workshop。

Coswara 即使通过也只能叫“小样本外部患者级压力测试”，不能叫外部确认性证明。
